Detection layers
Five checks, ordered by how easily weather fools them
L0 physics
Range · slew · dewpoint
L1 temporal
Spikes · steps · freezes
L2 joint
Cross-channel impossible
L3 sequence
Drift · noise bursts
L4 spatial
Buddy check vs neighbours
L0 physicsRange, slew rate, dewpoint ≤ temperature. Catches the impossible; weather never fools it.1.00
L1 temporalHampel on the forecast residual plus a stuck test. Catches spikes, steps, frozen sensors.0.85
L2 jointRobust Mahalanobis + Isolation Forest. Catches readings that are individually plausible but jointly impossible.0.75
L3 sequencePCA subspace reconstruction. Catches drift and noise bursts; most fooled by real weather.0.70
L4 spatialWMO buddy check against neighbours. Catches sustained bias a single station can't see in itself.0.90
